# Contact-Book-CLI-and-Sorting-Algorithms

## Overview

This repository contains my Week 4 Python Internship Project completed during my internship at AlgoHub. The project focuses on strengthening fundamental concepts of Data Structures and Algorithms through two command-line applications:

- Sorting Algorithms
- Contact Book CLI Application

The goal of this project was to understand how different data structures and algorithms work, implement them from scratch, and apply them to solve real-world problems.

---

## Features

### Sorting Algorithms

The sorting module demonstrates the implementation of common sorting algorithms without relying on Python's built-in sorting methods.

Implemented algorithms:

- Bubble Sort
- Selection Sort
- Insertion Sort

Users can:

- Enter a list of numbers.
- Choose a sorting algorithm.
- View the sorted output.
- Compare the behavior of different algorithms.

### Contact Book CLI

The Contact Book is a menu-driven command-line application for managing contacts efficiently.

Features include:

- Add a new contact
- View all contacts
- Search for a contact
- Update contact information
- Delete a contact
- View recent actions (history)

## How to Run

Clone the repository:

```bash
git clone https://github.com/waqas-ullah-10/Contact-Book-CLI-and-Sorting-Algorithms.git
```

Navigate to the project directory:

```bash
cd Contact-Book-CLI-and-Sorting-Algorithms
```

Run the Sorting Algorithms program:

```bash
python sorting_algorithms.py
```

Run the Contact Book application:

```bash
python contact_book.py
```
